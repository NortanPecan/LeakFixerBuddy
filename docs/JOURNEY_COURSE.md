## 🌟 Концепция

### Сюжетная линия
Каждый пользователь — герой истории о трансформации. 30 дней — это 30 глав книги его жизни:

```
📚 Главы курса:
├── Неделя 1: "Пробуждение" — открытие силы внутри себя
├── Неделя 2: "Закалка" — тренировка тела и духа  
├── Неделя 3: "Восхождение" — покорение новых вершин
└── Неделя 4: "Мастерство" — становление лучшей версии себя
```

### Ключевые принципы
- **Интерактивность** — не просто читать, а делать
- **Прогрессия** — функции открываются постепенно
- **Мотивация** — награды, достижения, цитаты
- **Персонализация** — курс подстраивается под цель

## ⚙️ Механики

### 1. Карта путешествия
Визуальная карта с 30 станциями. Каждая пройденная — загорается:

```
⬜⬜⬜⬜⬜⬜⬜     Неделя 1: Пробуждение
⬜⬜⬜⬜⬜⬜⬜     Неделя 2: Закалка
⬜⬜⬜⬜⬜⬜⬜     Неделя 3: Восхождение
⬜⬜⬜⬜⬜⬜⬜⬜⬜  Неделя 4: Мастерство
```

### 2. Ежедневные задания
Не просто "прочитай", а "сделай и получи подтверждение":

```typescript
interface DailyTask {
  id: string
  type: 'action' | 'create' | 'complete' | 'check'
  target: string // что нужно сделать
  count?: number // сколько раз
  reward: number // очки
  autoVerify: boolean // автоматически проверяется
}
```

**Типы заданий:**
| Тип | Описание | Пример |
|-----|----------|--------|
| `action` | Выполнить действие | Обновить настроение |
| `create` | Создать что-то | Создать 1 привычку |
| `complete` | Завершить что-то | Выполнить 3 ритуала |
| `check` | Посмотреть экран | Посмотреть статистику |

### 3. Автоматическая проверка
Задания проверяются автоматически по данным в БД:
- Обновил настроение? → `mood` таблица
- Создал привычку? → `habit` таблица
- Выполнил ритуал? → `ritualLog` таблица

### 4. Мотивационные элементы

```
┌────────────────────────────────────┐
│  💬 Цитата дня                      │
│  "Маленькие шаги ведут к большим   │
│   переменам. Ты уже на пути!"       │
└────────────────────────────────────┘

┌────────────────────────────────────┐
│  🎯 Совет дня                       │
│  Сегодня попробуй записать вес     │
│  утром натощак — так точнее         │
└────────────────────────────────────┘
```

### 5. Рефлексия
Каждые 7 дней — мини-опрос:

```
📝 День 7: Недельная рефлексия

Что получилось лучше всего?
[ Свой ответ ]

Что было сложным?
[ Свой ответ ]

Оцените неделю: 😞 😐 🙂 😊 🤩
```

## 🛠️ Техническая реализация

### Prisma Schema

```prisma
// Прогресс курса
model JourneyProgress {
  id          String   @id @default(cuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id])
  
  currentDay  Int      @default(1)
  startedAt   DateTime @default(now())
  completedAt DateTime?
  
  goal        String?  // выбранная цель
  
  tasks       JourneyTask[]
  achievements JourneyAchievement[]
  
  @@unique([userId])
}

// Выполнение заданий
model JourneyTask {
  id           String         @id @default(cuid())
  progressId   String
  progress     JourneyProgress @relation(fields: [progressId], references: [id])
  
  day          Int
  taskId       String
  completed    Boolean        @default(false)
  completedAt  DateTime?
  
  @@unique([progressId, day, taskId])
}

// Достижения пользователя
model JourneyAchievement {
  id          String   @id @default(cuid())
  progressId  String
  progress    JourneyProgress @relation(fields: [progressId], references: [id])
  
  achievement String   // ID достижения
  earnedAt    DateTime @default(now())
  
  @@unique([progressId, achievement])
}

// Разблокировки функций
model FeatureUnlock {
  id          String   @id @default(cuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id])
  
  feature     String   // название функции
  unlockedAt  DateTime @default(now())
  
  @@unique([userId, feature])
}
```

### API Endpoints

```
GET  /api/journey              - Получить прогресс курса
GET  /api/journey/day/:n       - Получить урок дня N
POST /api/journey/task/complete - Отметить задание выполненным
POST /api/journey/day/complete  - Завершить день
GET  /api/journey/achievements  - Получить достижения
GET  /api/journey/unlocks       - Получить разблокировки
```
