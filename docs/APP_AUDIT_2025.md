## 📱 UX/UI ПРОБЛЕМЫ

### 1. Отсутствие онбординга
**Проблема:** Пользователь заходит и видит 5 вкладок с кучей функций
**Решение:** Пошаговый онбординг с объяснением каждой функции

### 2. Сложная навигация
**Проблема:** Чтобы добраться до Tasks/Notes/Finance — нужно идти через Profile
**Решение:** 
- Добавить Quick Actions на HomeScreen
- Или переработать BottomNav на категории

### 3. Нет контекста
**Проблема:** "День 1", "Streak: 0", "Очки: 0" — что это значит?
**Решение:** Всплывающие подсказки при первом входе

### 4. Несогласованность UI
**Проблема:** 
- Где-то есть skeleton loading, где-то нет
- Где-то есть toast уведомления, где-то нет
**Решение:** Унифицировать паттерны
